# Security policy

## Supported versions

Wappler is a concluded proof-of-concept and has no supported production
release. The repository is retained for education and reference; security
updates and operational support are not guaranteed.

## Reporting a vulnerability

Do not include credentials, private audio, phone numbers, webhook payloads, or
other sensitive data in a public issue.

If GitHub offers **Report a vulnerability** on this repository's Security page,
use that private channel. Otherwise, open a minimal public issue asking the
maintainer to establish a private contact channel, without including exploit or
sensitive details.

If a credential has been exposed, revoke or rotate it with the provider first.
Deleting the value from the latest revision does not remove it from Git history.
